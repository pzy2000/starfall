星落远航《隐私政策》
您首次启动游戏时，游戏会通过本弹窗展示隐私政策要点并请求您的同意，同意后游戏才会继续启动。完整网页版请点击：https://pzy2000.github.io/starfall/

一、我们是谁及适用范围

本政策由 pzy的工作室（以下简称“我们”）提供，适用于 星落远航 安卓游戏，应用包名为 com.pzy.starfallodyssey。本次更新日期为 2026-10-14。
游戏核心玩法为离线太空探索，不提供游戏内付费或广告服务。为落实未成年人防沉迷要求，自 1.5.0 版本起游戏接入 TapTap TDS 实名认证与防沉迷服务：启动游戏需联网，并登录 TapTap 账号完成实名认证（详见下文）。点击「同意并继续」后，游戏在前台准备易玩（上海）网络科技有限公司的 TapSDK 4.10.9；SDK 会读取 AndroidID 等必要设备信息，用于登录、实名与防沉迷校验、设备兼容及故障排查。本游戏关闭 TapTap 数据分析和广告标识符采集，不主动读取 OAID、手机号或 IMEI。点「不同意并退出」则不启动游戏、不初始化 TapSDK。离线游戏仍可能在设备上处理存档、设置、设备运行信息及传感器能力信息，具体说明见下文。
本政策不替代 TapTap、TapPlay、Android 系统、您选择的文件服务或 GitHub 自身的隐私规则。使用这些独立服务时，请同时阅读相应提供方的告知。

二、我们处理哪些信息，为什么处理

1. 游戏进度与设置
为创建角色、继续游戏和保存进度，游戏在设备本地保存您设置的飞行员名称、阵营、舰船及装备、任务、物品、游戏进度和保存时间。画质等设置也保存在本地。请不要在飞行员名称中填写真实姓名、手机号码等不必要的个人资料。
处理时机：您创建角色、手动保存、入站、跨星系移动及应用生命周期触发保存时；更新设置时保存对应偏好。处理方式：写入、读取应用存储中的文件或偏好设置。本地存档由游戏保存。Android 版另提供经您确认后关联 TapTap 账号的云存档，用于备份与跨设备恢复；首次关联旧存档和恢复冲突需您确认，云存档故障不覆盖本地进度。
2. 主动导入的文件
当您主动选择导入旧存档时，Android 系统文件选择器会将您选中的 JSON 文件及其文件名、类型、大小等元数据提供给游戏。游戏校验并读取该文件，在应用缓存中暂存副本，用于转换和恢复游戏进度；成功导入后的临时副本会清理。导入不会修改您选择的原文件。
您可以取消文件选择，不影响其他玩法。该功能不会要求您授予整个存储空间的访问权。若选择的是云盘中的文件，下载及认证行为由您选择的文件提供方按其规则处理。
3. 设备适配和传感器能力信息
为运行图形、音频、输入和横屏适配，Unity 引擎及系统组件会在设备上访问与运行环境有关的信息，例如系统与图形能力、屏幕尺寸、密度、窗口方向及可用传感器信息。当前版本经平台检测存在 读取特定类型传感器列表 的行为，详见第三方组件说明。
我们不将上述信息用于广告画像或跨应用追踪，也不收集您的精确位置、通讯录、短信、通话记录、相册、麦克风音频或摄像头影像。游戏不含 AI 对话功能，也不向模型发送玩家数据；使用 AI 制作美术素材不等于向 AI 服务传输您的信息。
4. 主动联系与反馈
当您主动反馈问题时，我们会处理您提交的联系方式、问题描述和自愿提供的截图或日志，以便答复、排查问题及处理您的请求。请仅提供解决问题所需的信息，并先移除无关个人资料。
5. 实名认证与防沉迷
为遵守未成年人保护相关法规，游戏接入易玩（上海）网络科技有限公司提供的 TapTap TDS 实名认证与防沉迷服务。启动及校验时：您登录的 TapTap 账号标识（openid）由游戏提供给该服务，用于关联防沉迷状态；实名信息（如姓名、身份证号码）由该服务的认证界面直接收集，并上报国家新闻出版署防沉迷实名验证系统。游戏开发者不获取、不存储您的实名信息明文，仅收到认证结果与年龄段。未成年人仅可在周五、周六、周日及法定节假日的 20:00 至 21:00 进行游戏，并有单日时长限制；具体规则以服务端下发为准。处理方式：经由该 SDK 及其服务端通过网络传输。

引擎启动或初始化相关子系统时可能查询，应用重新启动、恢复或设备配置变化时可能再次查询；具体次数由引擎和系统运行情况决定，不设置额外的业务定时采集任务。
处理范围
本游戏用这些能力支持本地运行。当前项目未启用 Unity Ads、Unity Analytics、Unity Purchasing 和崩溃上报服务；这不等于宣称 Unity 框架不访问任何设备信息。Unity 其他产品的广泛数据说明不代表本游戏启用了全部 Unity 服务。

四、系统权限与选择

· 网络访问（INTERNET）：当前 APK 声明了网络访问权限，用于防沉迷实名认证与启动校验；核心游戏玩法（太空探索、战斗、交易）离线进行，断网不影响已保存的本地存档。该权限为 Android 普通权限，不会产生运行时授权弹窗。
· 文件读取：存档导入通过系统文件选择器获得您选定文件的临时读取授权。您可以取消，不会因此扫描其他文件。
· 传感器与屏幕适配：引擎可能访问传感器列表及屏幕、窗口信息，目的、方式和时机见上节。系统可能不提供单独关闭传感器列表查询的应用权限开关。
· 应用内部接收器权限：安装包包含以本应用包名标识的内部接收器权限，用于应用内部通信控制，不属于请求访问您个人内容的危险权限。
您可以在 Android 设置中管理应用权限、清除数据或卸载游戏。拒绝可选文件导入仅影响导入功能；如果您不接受运行游戏所必要的设备信息处理，可以停止运行或卸载游戏。阅读本网页本身不表示您已同意游戏在设备上处理信息。

五、信息存储、共享与安全

游戏进度和偏好保存在您的设备中，直至被后续保存覆盖、被您清除或随卸载删除。您自行导出的文件和系统、云盘保存的备份可能仍然存在，需要在对应位置单独删除；操作系统的备份与恢复也由您的系统设置决定。
我们不出售或出租您的个人信息。除您主动要求的处理、向您明确告知并取得必要授权的情形或法律要求外，不向其他主体提供您反馈给我们的个人资料。如您选择在公开平台反馈问题，相关内容可能被公开访问；隐私请求请优先使用下方联系邮箱。
本政策页面由 GitHub Pages 托管，访问网页时托管方可能处理 IP 地址、浏览器请求信息及访问日志，相关处理可能发生在其境外基础设施。我们没有在此页面加入统计脚本、广告、追踪像素、Cookie 或需要加载的第三方字体。GitHub 的处理规则见 GitHub 隐私声明。
我们采取最小化访问、应用存储隔离和必要的安全措施保护信息。设备丢失、第三方备份及您主动分享文件仍可能带来风险，请妥善保管设备和存档。

六、您的个人信息权利

您可以查看并修改游戏中允许修改的角色信息和设置，通过保存覆盖旧进度，并通过系统应用设置清除本地数据。清除数据或卸载前请先备份希望保留的进度。本地存档和云存档按您确认的 TapTap 账号关联；防沉迷验证依赖 TapTap 账号登录，TapTap 账号及其关联的实名信息需向 TapTap 平台申请注销或删除。
如需查询、复制、更正或删除您主动提供给我们的信息，撤回有关授权，或对处理方式提出异议，请通过下方联系渠道提出请求。我们将在核实必要信息后依法处理；对不能执行的请求说明理由。我们不会为核实一个简单问题而要求您提供不必要的身份证件。

七、未成年人保护

未成年人应在监护人的指导下阅读本政策。涉及依法需要监护人同意的个人信息处理时，应先取得监护人同意。游戏自身不收集儿童的姓名、身份证件或联系方式；实名认证与防沉迷由游戏接入的 TapTap TDS 服务实施，实名信息经该服务上报国家新闻出版署防沉迷实名验证系统。未成年人仅可在周五、周六、周日及法定节假日的 20:00–21:00 游戏，并有单日时长限制。
监护人若发现未成年人向我们提供了不必要的个人信息，可以通过下方渠道请求处理。请勿在公开反馈中提交儿童身份信息。

八、政策更新

游戏功能、第三方组件或信息处理方式发生变化时，我们会更新本政策及页面日期。对于依法需要重新告知或取得同意的重大变更，应在相关处理开始前进行告知并取得必要同意，不以网页更新替代必要的同意流程。
