# 星落远航 / STARFALL ODYSSEY privacy policy

GitHub Pages site for the privacy policy of the Android game 星落远航
(STARFALL ODYSSEY, package `com.pzy.starfallodyssey`). Canonical URL:
https://pzy2000.github.io/starfall/

Contents:

- `index.html` — the full policy page (revision 2026-10-14, matching the
  in-app first-launch consent popup of builds with the TapSDK 4.10.9 and cloud saves).
- `privacy/index.html` — redirect to the canonical URL for deep links.
- `.nojekyll` — skip Jekyll processing.

Only policy HTML and this README are published. No game builds, signing
files, user data or local experiment artifacts are included.

The repo must stay **public**: GitHub Pages on the free plan cannot publish
from a private repository. The game source repository remains private and
unrelated to this site.
